# 固定当前的report切分方式，其输出均为后续使用时的一个检索单元

目前有五种实现，为每一个实现增加其对应参数，semantic应包含检索器参数

1. default: 按句子切分，以单句为单元。
2. raw: 不切分，直接使用原report，以原始report为单元。
3. ctx_window: 在按句子切分的基础上，增加上下文窗口，使用参数ctx来控制，表示按句子切分后取其上下相邻句子的数量。
ctx=k代表取上面相临k条，下面相邻k条，当一个report内没有更多可取句子时，到实际可取句子为止，其他report不参与。以某个窗口内的句子为单元，不同窗口可能有重复句子。
4. semantic: 在按句子切分的基础上，为一个report中每一对相临的句子计算相似度，当相似度大于参数$\theta$时，保留该句子对，当相似度小于参数$\theta$时，认为下一句子不连续，将之前连续的句子作为一个单元，下一句子继续与之后的句子做该操作。
5. ctx_semantic: 在semantic，将句子换成一个窗口，用ctx控制，ctx=k时，使用k条句子作为一个相似度计算单元，为这些单元做相似度匹配。

# Abstract

社交媒体的发展提高了虚假新闻的传播效率，这使得基于证据的自动的可解释虚假新闻检测方法成为热点。
在已有方法中有的使用复杂的证据特征，也有的将证据通过复杂组织变换以及解释来得到结果。
这些方法往往依赖事后的解释，如：在真实性标签判定后才单独输出解释文本。
而在真实人类检测虚假新闻场景中，人类往往是按照证据一步一步组织构成可解释的证据链来得到最终判别的。
这启发我们，将某条声明可得的所有证据按照特定方式切分，并按声明中的原子级事实逐个解释的顺序编排，从而得到一条有序证据链。
该证据链既可以作为LLM的判断输入，也可以人类可读的可解释信息。
经过这种简单的编排后，在LLM上的微调结果表明，我们的方法超越了大部分包含复杂证据组织形式的自动事实核查方法，
同时，在与映入额外外部证据以及完全时使用闭源模型的agent方法的比较中也具有竞争性。

# Introduction

近年来，自动事实核查领域快速发展，从一开始的基于声明直接判断，到面向社交媒体的基于评论的检测系统以及面向新闻的基于证据的检测系统。
其中值得注意的是基于证据的检测系统，这种系统接受与一个声明以及与该声明相关的从互联网得到的各种原始报道，而后将这些报道通过各种方式精炼出可用于事实核查的数据结构。
有的是使用基于证据特征的级联方式[CofCED]，有的是基于LLM生成辩护[L-defense]或辩护图[G-defense]，又或者构建复杂的Agent系统[DelphiAgent]来完成整个过程。
而这些方法往往需要一套复杂的证据处理流程，如[CofCED]使用了一套证据特征聚合机制，将完整证据池构建成特征向量供后续判别器分类，而[L-defense]则借助群体智慧思想，利用LLM生成对证据的正反辩护而后在输入后续的分类器，[G-defense]则更近一步，该方法把一个完整声明拆成了多个子声明，构成一个图，而后为每个声明都生成正反辩护，最后将图序列化接入到分类器。通过大致观察可发先，这一系列方法最终输入到分类器的数据结构都已经不再是原始证据的形式，导致了黑箱问题，进而可解释性可能比较薄弱。

人类在进行事实核查时，会经过多个步骤：1）信息收集：对一个声明，收集其所有相关的原始报告并整理；2）要素抽取：把一个声明拆分成多个原子事实，每个原子事实都包含最小的子命题；3）证据组织：判断每一条证据支持了声明的哪一部分，并组织成一条逻辑链；4）来源评估及矛盾识别：检查report来源的可信度，以及处理证据中存在的矛盾；5）结论形成：根据所有信息得出最终判决。

随着大模型技术的发展，大模型展示出了强大的逻辑推理能力，使其可以完成许多以前人类才能完成的推理流程。结合人类事实核查流程，这启发我们，能否在一定程度上利用大模型的推理能力，构建一套可以模仿人类进行事实核查的流程

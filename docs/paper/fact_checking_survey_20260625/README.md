# Fact-checking Survey Report

This directory contains the Chinese research report built from the `docs/paper/tanggeng/Bg.tex` style.

Build from this directory:

```bash
bash build.sh
```

Main files:

- `fact_checking_survey.tex`: report source.
- `refs.bib`: bibliography used by `biblatex`/`biber`.
- `build.sh`: reproducible XeLaTeX build command.

## 口径说明

- 收录 verifier final 指标与 oracle upper-bound；不收 selector recall/top1、train-only oracle、shard metrics；训练 step 曲线不单独成行。
- 任一 split 有最终 `val` 或 `test` 指标即收录；缺失 split 在表中留空，并在详细说明标记 `val missing` 或 `test missing`。
- 主表只保留版本号、简单设置、模型/训练方式和 val/test accuracy / macro-F1；selection score、路径、source、status、notes 等详细字段放在表后列表。
- 对 label-token 训练 run，如果没有独立 `eval/val/best/label_token/metrics.json`，但存在训练期 `eval/step-*` 或 `train/eval/step-*` val metrics，则用最高 val `selection_score` 的 step 作为 adopted val，并在详细说明标记来源。
- 每个实验版本只保留一个 adopted setting。优先使用项目文档明确指定的采用口径；否则有 val 时按 val `selection_score` / `macro_f1` 选择，没有 val 时按 test 选择。
- `model_transfer` 指 RAWFC phase7 backbone migration / transfer matrix，来源主要是 `outputs/selector_trace_verifier/rawfc_v0_6c_eval25_backbone/`，采用 `eval/test/best/label_token/metrics.json`；其 val 多来自同一训练 run 的 `eval/step-*`。
- `outputs/runs` 和 `_scratch` 中缺少 `label_schema` 的旧 metrics 会用路径、per-class label、split size 和相邻 config 推断数据集，并在 CSV 中标记 `dataset_inferred=true`。
- 版本号按数据集独立编号：LIAR-RAW 为 `LR-vNNN`，RAWFC 为 `RF-vNNN`。编号按研究线排序，不按性能排序。
- `row_type=oracle_upper_bound`、`status=scratch`、`status=legacy` 的结果只用于参照，不应直接当作普通可采用模型结果。

扫描到的候选 final metric 文件数：`182`；另用训练期 step-val metrics 补入 RAWFC adopted val `40` 行。最终主表行数：LIAR-RAW `52`，RAWFC `46`。RAWFC 有 val 指标 `45` 行，其中 `40` 行来自训练期 step-val metrics。

## Oracle / Legacy / Scratch 标记说明

- `row_type=oracle_upper_bound`：oracle evidence、oracle direct verifier、pointwise/oracle-selector 等上界或诊断结果，不能与普通检索/selector/verifier 模型直接按可部署结果混比。
- `status=legacy`：历史归档或 backbone migration 结果，保留用于追溯。
- `status=scratch`：临时搜索目录，例如 `outputs/rl_mmr/sensitivity_search/_scratch`，保留用于完整盘点。
- `dataset_inferred=true`：metrics 没有直接给出可识别 schema，数据集来自路径、per-class label、split size 或相邻 config 推断。
- `eval/step-*` / `train/eval/step-*`：训练期 validation eval，不是单独的 final val rerun；本表仅在缺少 `eval/val/best/label_token/metrics.json` 时用它补 adopted val。

## 已排除项

- `oracle_metrics_train*.json` 与 `*.shard-*`。
- 只作为训练曲线且没有对应 adopted run/test 的 step metrics。
- `infer/*/checkpoint-*` 非 adopted final checkpoint 复查结果。
- selector-only 指标，例如 `selector_metrics.json`、`selection_metrics.json`、`retrieval_metrics.json`。
- 没有 `accuracy` 或 `macro_f1` 的 JSON。
- `outputs/selectors/selectors/` 剩余同步异常文件没有作为单独来源扫描；这批文件需要先确认是否应迁移回主输出根。
